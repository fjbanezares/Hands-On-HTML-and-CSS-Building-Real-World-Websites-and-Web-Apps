🔍 Reflexión didáctica: ¿Cómo funciona esta API y qué viaja en las cabeceras HTTP?

1. ¿Qué es una API? Es una interfaz que permite a nuestra web pedirle datos a otro servidor sin recargar la página. Con fetch(url) enviamos un "pedido" a través de Internet y recibimos una respuesta estructurada en formato JSON.

2. El papel crucial de las Cabeceras HTTP (Headers): Todo intercambio en la web lleva "metadatos en el sobre". Nuestro navegador envía cabeceras como User-Agent y Accept, y el servidor nos devuelve cabeceras como Content-Type: application/json (indicando que lo que viaja dentro es texto codificado en JSON) y Access-Control-Allow-Origin: * (CORS, que autoriza a nuestro navegador a leer el dato).
